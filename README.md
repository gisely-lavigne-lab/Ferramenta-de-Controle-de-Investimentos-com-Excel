# Ferramenta de Controle de Investimentos com Excel
É uma ferramenta de controle de investimentos imobiliários feita com o excel.

## Perguntas que a ferramenta responde:
- Quanto investir por mês?
- Por quantos anos?
- Qual a taxa de rendimento mensal?
- Quanto de patrimônio vai acumular?
- Quanto vai receber de dividendos por mês?
